Connect your account

This extension works with a personal API key from your Lightning Gifts account.

  1. Sign in at lightning.gifts.
  2. Open Profile → Developer API Keys.
  3. Create API key and paste it below. Treat it like a password — it acts as your account with no scopes and no expiry, and you can revoke it any time from the same panel.

Lightning Gifts is not a wallet, an exchange, or a bank: gift sats sit with the service only between funding and the recipient's withdrawal. The key travels only to lightning.gifts, in an Authorization header — never in a URL, a log, or a share sheet.
